Bakgrund

Arbetsförmedlingen arbetar med att digitalisera ansökningsprocesser som tidigare varit pappersbaserade. Ett sådant projekt var Moderna beredskapsjobb, ett ekonomiskt stöd till statliga myndigheter som anställde långtidsarbetslösa eller nyanlända.

Min roll var att intervjua intressenter och användare samt kartlägga processen för att definiera projektets omfattning.

Resultatet blev ett mer effektivt och lättanvänt ansökningsformulär. Genom kopplingar till databaser kunde uppgifter fyllas i automatiskt utifrån användarens inmatning, samtidigt som myndigheterna kunde ansöka om ytterligare stöd beroende på hur många personer de planerade att anställa.
