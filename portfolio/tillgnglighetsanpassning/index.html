Tillgänglighetsanpassning - LF

Bakgrund

Appen hade tidigare genomgått flera tillgänglighetsförbättringar, men saknade ett sätt att anpassa gränssnittet efter användarens valda textstorlek i iOS och Android. Inför de nya tillgänglighetskraven från EU behövde vårt team möjliggöra textförstoring i apparna. WCAG 2.2 AA utgjorde organisationens målsättning för tillgänglighetsarbetet.

Min uppgift var att tillsammans med en UI Designer ta fram övergripande riktlinjer för skalbar text och specificera hur appens komponenter skulle bete sig vid olika textstorlekar. Riktlinjerna skulle sedan dokumenteras och användas av samtliga appteam.

Underlag och design principer

Eftersom funktionen ännu inte var implementerad saknade vi egen användningsdata. Vi utgick därför från extern data om hur människor använder textinställningarna i iOS och Android. Datat visade att mellan 20-30% avvek från standardinställningarna.

Utifrån detta definierade vi två nivåer: 
Upp till cirka 140 % skulle appen så långt som möjligt behålla samma informationsstruktur och komponentlayout som vid standardstorleken. Syftet var att ge kunderna en förutsägbar och sammanhållen upplevelse utan onödiga förändringar i gränssnittet.

Radkomponenten är en mångsidig komponenterna, vilket ökade komplexiteten för hur beteendet skulle definieras.

Vid större textstorlekar skulle komponenterna övergå till anpassade layouter, exempelvis genom radbrytning, vertikal placering eller utökad höjd. Där prioriterades enkel tillgång till allt innehåll och funktionalitet framför att bevara den ursprungliga layouten.

Eftersom vårt designsystem innehöll ett stort antal komponenter, kunde inte allt anpassas samtidigt. För att skapa största möjliga effekt tidigt tog vi fram användningsdata för appens mest besökta vyer och inventerade vilka komponenter de innehöll. Utifrån detta prioriterade vi de komponenter som var viktigast och användes mest.

Resultat

Arbetet resulterade i gemensamma riktlinjer och specifikationer som gav appteamen ett underlag för framtida implementation och kvalitetssäkring.

Efter lanseringen kunde vi för första gången följa hur kunderna faktiskt använde förstoringsfunktionen. Datan visade att 99 % använde en textstorlek under 140%, vilket bekräftade att brytpunkten gav nästan alla kunder en större text utan att i onödan förändra appens informationsstruktur.
